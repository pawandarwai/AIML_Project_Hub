## 📝 How to Add Your Project

Agar aap is class ke student ho aur apna project add karwana chahte ho, to neeche diye steps follow karo:

1. Is repo ko **fork** karo.
2. `README.md` file ke table me apni row add karo (project name, leader, members, tech stack, repo link).
3. Apna project ka **link public rakho** taaki sab access kar sakein.
4. Ek **Pull Request** bhejo — usko review karke merge kar diya jayega.

**Ya phir**, agar aap directly maintainer ho, to apna project detail is form/WhatsApp group me share karo, main ise table me add kar dunga.
